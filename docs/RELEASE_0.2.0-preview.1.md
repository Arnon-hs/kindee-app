# KinDee 0.2.0-preview.1

Test release of the open client. Contains the PWA demo and Android phone/Wear OS debug APKs. Client source includes the iPhone/Apple Watch projects, but this release does not contain a signed IPA or watchOS binary.

Public demo: recipes, portion calculations, food diary, corrections, profile and progress. Demo values are illustrative, and entries are cleared on reload. The normal/native client needs a reachable private platform API and a provisioned account for onboarding and health imports.

Android native code has a Health Connect bridge and a Wear OS companion. Physical-device synchronization is not yet validated. Apple builds require macOS/Xcode and device signing. The photographed proprietary watch remains unidentified and is not claimed as supported.

There is no working GrabFood/LINE MAN menu or delivery integration. See README.md, docs/PWA.md and docs/HEALTH_AND_ONBOARDING.md for setup and limitations.
